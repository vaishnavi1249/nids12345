# Sahayak NIDS: Real-Time Network Intrusion Detection & Threat Classification

A production-ready Full-Stack Network Intrusion Detection System (NIDS) that leverages Machine Learning to ingest raw socket packet layers, aggregate metrics into active network flows via a sliding micro-flow window accumulator, and classify threats into four targeted operational vectors: **Normal, Port Scan, Brute Force, and DDoS** in real time.
